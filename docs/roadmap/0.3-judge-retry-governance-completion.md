## Implemented Capabilities
1. Judge/evaluator maturity (`RMD-032`)
- Runtime behavior:
  - `judge.rubric` delegates through codergen with required rubric path and score threshold checks.
  - Emits explainability context updates (`score`, `score_threshold`, `passed`, `rubric_path`, `score_weights`).
- Implementation and verification:
  - `packages/core/src/handlers/builtin.ts`
  - `packages/core/src/handlers/builtin.test.ts`
  - `tests/golden/workflows/judge-rubric.dot`
  - `tests/golden/expected/judge-rubric.json`

2. Targeted retry + failure taxonomy hardening (`RMD-033`)
- Runtime behavior:
  - `failure.analyze` enforces structured taxonomy output (`transient`, `quality_gap`, `tool_error`, `spec_mismatch`).
  - Engine routes targeted retries by failure class via direct attributes and/or `retry_target_map`.
- Implementation and verification:
  - `packages/core/src/handlers/builtin.ts`
  - `packages/core/src/engine/index.ts`
  - `packages/core/src/engine/targeted-retry.test.ts`
  - `tests/golden/workflows/failure-analyze.dot`
  - `tests/golden/workflows/targeted-retry-routing.dot`

3. Promotion + governance profile enforcement (`RMD-034`)
- Lint policy enforcement:
  - Validates `promotion_stage`/`quality_profile` compatibility.
  - Enforces strict overlays (quality gate presence + codergen output contracts).
  - Enforces regulated overlays (non-custom gate types + at least one `judge.rubric`).
- Implementation and verification:
  - `packages/core/src/lint/index.ts`
  - `packages/core/src/lint/index.test.ts`
  - `tests/golden/workflows/promotion-regulated.dot`
  - `tests/golden/expected/promotion-regulated.json`
