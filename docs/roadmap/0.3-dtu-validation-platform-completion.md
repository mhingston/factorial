# 0.3.x DTU Validation Platform Completion

Last updated: 2026-02-11

## Scope
- Parent roadmap: [`ROADMAP.md`](../../ROADMAP.md)
- DTU milestone plan: [`0.3-digital-twin-universe-execution-plan.md`](./0.3-digital-twin-universe-execution-plan.md)
- Covers roadmap item: `RMD-030` (Digital Twin Universe validation platform)

## Implemented Capabilities
1. Twin contracts and runtime boundary (`AT-01`, `AT-02`)
- Contract schemas: `packages/core/src/dtu/contracts.ts`
- Runtime boundary + in-memory runtime: `packages/core/src/dtu/runtime.ts`
- Reference twins:
  - `packages/core/src/dtu/twins/jira-issue.stub.ts`
  - `packages/core/src/dtu/twins/slack-channel.stub.ts`
- Deterministic parity tests:
  - `packages/core/src/dtu/reference-parity.test.ts`

2. Scenario harness and holdouts (`AT-03`, `AT-04`)
- Harness module: `packages/core/src/dtu/scenario-harness.ts`
- CLI command: `factorial dtu-run` (`packages/cli/src/index.ts`)
- Fixture corpus: `tests/fixtures/dtu/scenarios/*.json`
- Report schema fields include totals, pass rate, holdout rate, and drift deltas.

3. Failure-mode simulation coverage (`AT-05`)
- Deterministic simulation knobs implemented in twins and fixtures for:
  - rate limit
  - auth failure
  - timeout
  - malformed payload
  - partial outage
- Coverage assertions in `packages/core/src/dtu/scenario-harness.test.ts`.

## Artifacts and CI
- Local command:
  - `npm run dtu:run`
- CI coverage:
  - `.github/workflows/ci.yml` runs DTU scenario harness on Node 20.

## Out of Scope
- `RMD-031`, `RMD-032`, `RMD-033`, and `RMD-034` remain separate roadmap items.
- Cross-provider codergen parity and promotion-threshold gates are not part of `RMD-030` completion.
