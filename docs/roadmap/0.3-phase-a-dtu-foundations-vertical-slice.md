## What This Slice Implements
1. Schema-backed DTU invocation contracts
- Request, response, error classes/codes, and deterministic timing model.
- File: [`packages/core/src/dtu/contracts.ts`](../../packages/core/src/dtu/contracts.ts)

2. Backend-agnostic runtime boundaries
- `TwinRuntimeBoundary` and `TwinRegistryBoundary` interfaces.
- In-memory runtime implementation for CI/local deterministic execution.
- File: [`packages/core/src/dtu/runtime.ts`](../../packages/core/src/dtu/runtime.ts)

3. Reference twin stub
- `JiraIssueTwinStub` for deterministic operation replay (`issues.create`).
- File: [`packages/core/src/dtu/twins/jira-issue.stub.ts`](../../packages/core/src/dtu/twins/jira-issue.stub.ts)

4. Deterministic fixture parity tests
- Fixtures: [`tests/fixtures/dtu/jira-issue/*.json`](../../tests/fixtures/dtu/jira-issue)
- Tests: [`packages/core/src/dtu/reference-parity.test.ts`](../../packages/core/src/dtu/reference-parity.test.ts)
