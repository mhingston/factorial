## Implemented Capabilities
1. Repository-native dogfood runtime
- Command: `npm run dogfood:self-host`
- Runtime script:
  - `scripts/self-host-dogfood.js`
- Behavior:
  - Generates deterministic DOT workflows for `resolved` and `reopen` lock paths.
  - Runs this project via local CLI (`dist/packages/cli/src/index.js`).
  - Executes bounded stages: Plan -> Work -> Review -> Compound -> Lock -> Manager.
  - Emits deterministic report artifact:
    - `<logs_root>/report.json` with schema `self_host_dogfood_report.v1`.

2. Lock decision enforcement evidence
- `resolved` scenario:
  - expected pass (`exit_code=0`, manifest outcome `SUCCESS`).
- `reopen` scenario:
  - expected fail (non-zero exit, manifest outcome `FAIL`).
- Enforcement point:
  - `stack.manager_loop` with required lock decision.

3. Automated regression coverage
- Test:
  - `packages/cli/src/self-host-dogfood.test.ts`
- Assertions:
  - report schema shape,
  - scenario count and names,
  - pass/fail expectations and manager lock values.
